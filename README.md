# Tadabor

Tadabor is a Quran search and Mushaf reader packaged for Android with a local-first architecture.

## Offline-first guarantees

- Quran text is bundled locally in `src/data/quranData.json`.
- 604-page verse/page mapping is bundled locally in `src/data/quranPages.json`.
- Surah metadata is bundled locally in `src/data/surahs.json`.
- The Mushaf reader uses local data only; it does not call Quran.com or another remote API.
- The Android build removes the `INTERNET` permission.
- No backend is required to run the app.

## Build the web bundle

```bash
npm install
npm run build
npm run offline:check
```

## Prepare Android

```bash
npm run mobile:prepare
```

The Android project is generated by Capacitor and uses `dist/` as its local WebView bundle.

## Build APK

```bash
npm run android:build
```

The debug APK is produced at:

`android/app/build/outputs/apk/debug/app-debug.apk`

## Storage policy

Tadabor does not create an application data directory in shared/public storage for its core content. The required Quran resources are packaged with the application. Any runtime state should stay in Android app-specific storage so Android can remove it with the application on uninstall.
